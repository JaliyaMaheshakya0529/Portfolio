# React portfolio with Lenis + full-page section navigation

## Run

```bash
npm install
npm run dev
```

## Customize

- Edit `profile` in `src/App.jsx` for your name, role, and email.
- Edit `projects` in `src/App.jsx` to replace placeholder entries with real projects.
- Edit section copy in `src/App.jsx` and styles in `src/index.css`.

## Navigation

- Mouse wheel goes exactly one section at a time; Lenis animates the travel.
- Arrow keys, Page Up/Down, Home/End, Space, touch swipes, and header links navigate sections.
- Respects reduced motion preferences.
